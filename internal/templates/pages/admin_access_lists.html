Access Lists

Projects Users Robot Users Group Mappings Global Access Access Lists

A named set of users and groups that projects can share. Give a project the visibility of a list here and exactly its members can reach it — useful when several projects have the same audience.

A member naming a user applies right away. A member naming an LDAP or OAuth2 group reaches each user at their next sign-in, since group membership is only known then.
